## Reading this table

Sentiment macro-F1 leads over accuracy because positive reviews dominate; a model that always answers "positive" scores well on accuracy and badly here.

Issue macro-F1 averages over categories, so a rare-but-expensive category (defects) counts as much as a common one. Per-category numbers, including which labels were too rare to score reliably, are in the matching `*_report.json`.

**Two runs are only comparable when the `Data` hash matches.** A different hash means different rows, and the numbers are not measuring the same thing.
